# Clinic Management System 🏥

A full-stack Clinic Management System designed to simplify clinic operations, patient registration, doctor visits, and digital prescription management.

The application provides role-based access for doctors and receptionists, allowing them to manage patient records, track visits, maintain medicine information, and create prescriptions through a structured backend architecture.

## Key Features

- **Role-Based Authentication:** Secure registration and login for doctors and receptionists using JWT, HTTP-only cookies, and bcrypt password hashing.
- **Patient Management:** Register and maintain patient records with contact details and queue information.
- **Visit Management:** Create and manage doctor visits linked to patients.
- **Medicine Management:** Maintain medicine records, including generic names, strengths, and dosage forms.
- **Digital Prescriptions:** Create and retrieve prescriptions linked to patients, doctors, visits, and medicines.
- **Search & Filtering:** Retrieve prescription records using visit, patient, and medicine filters.
- **Protected APIs:** Authentication middleware and role-based authorization to control access to endpoints.

## Technology Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Tokens (JWT)
- bcrypt
- Postman

## Project Goal

This project is being developed as a practical backend engineering project to implement real-world REST API development, authentication, authorization, database relationships, data validation, and scalable backend architecture.

More features and improvements are planned as development progresses.
